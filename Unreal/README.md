# Portage — Unreal exporter

Python editor scripts that export assets from an open Unreal project into a folder described by a
[manifest](../Docs/manifest-format.md).

**Not implemented yet.** Development targets Unreal Engine 5.8 and starts once the scripts can be
run against a real editor; the Unreal Python API names involved have not been verified.

Requires the *Python Editor Script Plugin*. No C++ and no engine source code is used or included.
